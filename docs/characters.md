# 角色与资源

三位都是人形桌宠；“大肥鱼”是圆润蓝发 Q 版女仆的昵称。

`dsh-pet/assets/pets/fish/` 存原版 106 段 WebM 与 27 张对话配图。
`whale/` 存鲸鱼娘动作、27 张配图和原项目插图。
`chatgpt/` 存 24 个静态 PNG 姿势（3 张 4×2 图集）、27 张独立配图及逐句同字数台词校验记录。
`duo/` 存八种双人静态场景（1 张 4×2 图集）；只在 DSH 大肥鱼与 GPT ChatGPT 娘都在线且桌宠开启时使用。

字体、指针与通知图标保留为共享资源。模型提示词、固定台词、配图路由和对话记忆按角色隔离，角色文件不存在时返回 404，不回落到其他桌宠图片。

右键“切换桌宠”会保存角色；手动用户输入和任务文字保持原文。

三个角色均由 `pet.json` 注册。新增角色、动作与状态映射见 [PetPack 接口](pet-pack.md)。乔思伯输出适配读取渲染器画布，不依赖具体角色。
